# ADR-006 — Adoção do PostgreSQL

- **Status:** Aceita
- **Data:** 02/11/2026

## Contexto

O sistema de gestão financeira necessita de um banco de dados para armazenar e gerenciar as informações dos usuários e suas respectivas movimentações financeiras.

Os dados incluem usuários, contas, categorias, receitas, despesas, transferências e investimentos, que possuem relacionamentos entre si e precisam ser armazenados de maneira consistente.

## Alternativas Consideradas

- **PostgreSQL:** Banco de dados relacional com ampla utilização no mercado e suporte a recursos avançados de gerenciamento e consulta de dados.
- **MySQL:** Banco de dados relacional também amplamente utilizado no mercado, considerado como alternativa ao PostgreSQL.

Bancos de dados não relacionais não foram considerados, pois o projeto possui uma estrutura de dados predominantemente relacional.

## Decisão

Foi decidido utilizar o **PostgreSQL** como sistema gerenciador de banco de dados do projeto.

A escolha foi motivada pela familiaridade prévia com a tecnologia, pelo interesse do desenvolvedor em aprofundar seus conhecimentos e pela ampla utilização do PostgreSQL no mercado profissional.

Embora o MySQL também fosse uma alternativa viável, optou-se pelo PostgreSQL por preferência e objetivos de aprendizado.

O banco de dados será responsável por armazenar as informações de todos os módulos da aplicação, mantendo os dados relacionados por meio de tabelas e relacionamentos.

## Consequências

### Positivas

- Permite aprofundar os conhecimentos em PostgreSQL por meio de um projeto prático.
- Utiliza uma tecnologia amplamente adotada no mercado profissional.
- Possibilita explorar recursos específicos do PostgreSQL conforme surgirem necessidades durante o desenvolvimento.

### Negativas

- A escolha limita a portabilidade imediata para outros SGBDs (sistema gerenciador de banco de dados), pois consultas, configurações e recursos específicos podem variar entre tecnologias.
- Será necessário manter conhecimentos sobre administração, configuração e otimização do PostgreSQL.

## Observações

O PostgreSQL será utilizado em conjunto com o Flyway para gerenciamento e versionamento das alterações na estrutura do banco de dados.

A estrutura das tabelas e os relacionamentos serão definidos conforme a modelagem dos dados e os requisitos funcionais do sistema.
